# دفتر الأمانات — لغز عائلي في جدة

لعبة تحقيق عربية لـ٦–١٠ لاعبين (٢–٤ فرق) على شاشة مشتركة. تدور في جدة المعاصرة بين أسرة حضرمية الأصل استقرت في الحجاز منذ أجيال.

> قصة خيالية. الأسرة والشخصيات والوثائق من تأليف اللعبة، وأي تشابه مع أشخاص أو أسر حقيقية غير مقصود.

## التشغيل

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run dev        # للتطوير: http://localhost:5173
npm run build      # بناء نسخة ثابتة في dist/
npm run preview    # تشغيل النسخة المبنية: http://localhost:4173
```

مجلد `dist/` ثابت بالكامل ويمكن رفعه على أي استضافة ملفات. للّعب على التلفاز: افتحوا الرابط في متصفح جهاز موصول بالشاشة.

## الاختبارات

```bash
npm test                       # ٢٦ اختباراً للمنطق وسلامة البيانات
npm run build && npm run e2e   # لعب كامل عبر المتصفح + لقطات في e2e/shots/
```

`npm run e2e` يحتاج مكتبة Playwright ومتصفح Chromium مثبتين على الجهاز.

## بنية المشروع

| المسار | المحتوى |
|---|---|
| `src/cases/daftar/index.ts` | بيانات القضية العلنية: شخصيات، أماكن، أدلة، حوارات، خط زمني، قيود منطقية، تلميحات |
| `src/cases/daftar/solution.ts` | الحقيقة المخفية والخاتمة؛ تُحمَّل في ملف منفصل عند الخاتمة فقط |
| `src/engine/` | الأنواع، حالة اللعبة والحفظ، منطق الشروط والفرضيات والتقييم |
| `src/ui/` | الواجهة والمشاهد المرسومة برمجياً |
| `tests/` · `e2e/` | الاختبارات |
| `docs/` | تقرير البحث، التصور، وثيقة الحل، تقرير الاختبارات |

لإضافة قضية جديدة: أنشئوا مجلداً تحت `src/cases/` يصدّر كائناً من النوع `CaseData` وآخر من النوع `Solution`، واستوردوه في `src/ui/App.tsx`. اختبارات `tests/case.test.ts` عامة وتصلح لأي قضية بعد تغيير الاستيراد.
